# 🎲 Number Generator

Projeto de sorteio de números desenvolvido com HTML, CSS e JavaScript.


## 🛠️ Tecnologias

* HTML
* CSS
* JavaScript


## ✨ Funcionalidades

* Sorteio de números com intervalo definido
* Opção com ou sem repetição
* Exibição animada dos números
* Layout responsivo

## 🕹️ Como utilizar

1. Defina o valor mínimo e máximo
2. Escolha a quantidade de números
3. Selecione se deseja repetição ou não
4. Clique no botão de sortear
5. Veja os números sendo exibidos na tela
